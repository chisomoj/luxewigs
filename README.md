# luxewigs — 100% Premium Human Hair Wigs

Chocolate & cream luxury theme (inspired by the Hair Day / Silk & Grace references). Brand: **luxewigs**.

- Every **SHOP / SHOP COLLECTION** button filters + scrolls to real products (`#shop`)
- Fully functioning cart: add / qty / remove / subtotal / localStorage + slide-in drawer
- Search, quick view, checkout with order summary + success state
- Footer: `Designed by Codewithfavour` → https://www.instagram.com/codewithfavour/
- Photos: drop your own Pinterest downloads into `images/` (see `images/README.md` for filenames) — the site uses local files first and falls back to studio photos automatically.

## Run locally
Open `index.html` or `npx serve .`

## Deploy
Vercel: import `https://github.com/chisomoj/luxewigs.git` (static, no build step).
