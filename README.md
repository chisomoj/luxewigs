# space. — Luxury Wigs, Frontals, Closures & Bundles

Inspired by shopmilang.com. Brand: **space**.

- Every **Shop Now** button filters + scrolls to real products (`#shop`)
- Fully functioning cart: add / qty / remove / subtotal / localStorage + slide-in drawer
- Search, quick view, checkout with order summary + success state
- Footer: `Designed by Codewithfavour` → https://www.instagram.com/codewithfavour/

## Run locally
Open `index.html` or `npx serve .`

## Deploy
Vercel: import `https://github.com/chisomoj/luxewigs.git` (static, no build step).
